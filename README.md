# Grand Park Cambridge Teachers' Hub

A one-page hub for Primary teachers and teaching assistants at Grand Park Cambridge Bilingual Campus.

**Live site:** https://malcolmgouws-coder.github.io/grand-park-primary-hub/

## What's inside
- Toolkit: Pacing Guides, Teacher Timetables, Lesson Plans, Good Teaching Practice, Behaviour Logs, Peer Observations, Learning Carpet Ideas, Policies & Procedures, Room Booking, Stationery Orders (filter + search)
- Our values, noticeboard, key dates, good practice spotlight, browse by stage

## Editing
- Everything is in `index.html`. Toolkit boxes are in the `all` list near the bottom of the file – change a box's text there.
- Replace any text in [square brackets] with real content.
- Images live in `assets/`.

For internal staff use.
